# dugou · inpiration / Design Editions

## 交付范围

三个独立方向、每个方向十个页面的交互原型：`/design/inpiration`。也支持 `/arsenal/design/inpiration`，但预览始终只用虚构数据，不调用 AI、不保存投资、不修改云数据。

这次把应用默认布局改为 `inpiration`，并在该主题导航增加「设计提案」。首次升级切换一次，后续记住用户手动选择的 Modern 或其他布局。Modern 的视觉保持原样；选定设计方向后，再接入实际业务页面。

原型展示方向、信息层级和代表性交互，不是三套已经完成全部业务接线的生产主题。现有算法、判定、导入导出和同步服务不在本次改写范围。

## 核心判断

dugou 的品牌核心可以从「体育投资工具」提升为「在不确定中，积累判断的系统」。浪漫来自时间、成长和个人档案；专业来自样本、风险、参数和可追溯记录。它们应该在同一个界面里成立。

品牌锚点沿用钻石 Logo，提取四切面：洞察、配置、结算、复盘。分别映射 New、Portfolio、Settle、Seasons，贯穿导航图标、周期封面、组合关系与空状态。

“成熟科技企业感”转化为可以执行的规则：一致组件、明确状态、稳定交互、可读文字、真实指标定义和可靠保存。视觉可以提升表达与可信度，不保证资本偏好或商业结果。

## 三个方向

| | HELIO · 日光档案 | KEPLER · 轨道实验室 | FOLIO · 未来刊物 |
|---|---|---|---|
| 品牌性格 | 明亮、灵动、自信 | 精密、冷静、探索 | 浪漫、人文、鲜明 |
| 主构成 | 横向玻璃导航 + 轻盈卡片画布 | 侧边观测导航 + 仪表式内容 | 刊头 + 章节 + 非对称折页 |
| 色彩 | 雾白、瓷白、冰蓝、少量香槟 | 石墨、钛灰、铂金、恒星金 | 棉纸白、墨色、鸢尾蓝、古铜 |
| 品牌几何 | 四切面透镜 | 中心钻石与坐标轨道 | 钻石展开成折页与书签 |
| 玻璃位置 | 导航、控制器、明细浮层 | 烟灰导航与铂金工具面 | 浮动书签、工具托盘、详情侧页 |
| 最适合 | 日常产品主体系 | 模型、研究、高密度专业信息 | 复盘、内容、长期品牌关系 |
| 需要控制 | 细节不能变成泛白低对比 | 深色不等于厚重发光 | 刊物叙事不能拖慢数据查询 |

### 01 / HELIO — 让每一次洞察，都有光

用暖白内容承载数据，用冰蓝折射承载交互。用户从“灵感”进入，再经过配置与结算，把一季收进档案。主要卡片有轻重之分，不把每个信息块都做成同等强调的玻璃盒。

- 层级：环境画布 → 瓷白内容 → 玻璃控制 → 浮层，最多四层。
- 主界面：横向紧凑导航，周期封面宽卡；十二指标构成细密但可呼吸的数据带。
- 图表：蓝色细线与低透明面积，盈亏仍用文字、正负号、语义色共同表达。
- 字体：系统无衬线；正文 14–16，辅助 12，标题约 32–38，关键数字 26–32；封面单一焦点允许略大。
- 动效计划：控件约 220ms，卡片约 360ms，章节约 640ms。光泽只服务位置和反馈。
- 品牌延展：四切面可以组成发布图、产品官网和周期分享封面，无须换一套营销视觉。

### 02 / KEPLER — 在不确定中，找到自己的轨道

不是深蓝大屏，而是中性石墨研究室。侧栏给复杂页面稳定的空间坐标，内容强调样本、敞口和计算依据。金色点只提示当前活动，不变成装饰主角。

- 主界面：左侧导航、右侧工作画布；数据形成连续仪表，圆轨道与矩形面板对照。
- 指标：点击后展示定义、窗口、样本；分析矩阵优先于叙事大标题。
- 字体：主要信息无衬线；小范围等宽体用于坐标、序号、模型标识，不用于长段正文。
- 材质：烟灰玻璃工具层 + 钛灰实底数据；不在每张卡上添加高光晕。
- 动效计划：状态 180ms，面板 300ms，轨道定位 600ms；持续运动只允许在小型活动指示器上。
- 品牌延展：适合产品研究演示、模型报告、专业工作台。需要更多纸面留白照顾长时间阅读。

### 03 / FOLIO — 把判断，写成值得回看的篇章

把 dugou 视为一本持续出版的个人判断刊物。Seasons 是期刊封面，New 是手稿，Portfolio 是编排，Settle 是校样。细线、页角编号和折页取代大量圆润小盒子。

- 主界面：刊头与章节，7:5 / 8:4 叙事编排；数据采用规整细网格，内容卡带折页角。
- 字体：英文叙事局部衬线；中文、表格和所有关键数字仍保持清晰的无衬线。
- 材质：棉纸实底 + 鸢尾色玻璃书签；透明材质只在导航控制和浮层出现。
- 动效计划：标签 240ms，卡片 420ms，折页 580ms；打开明细时保持原阅读位置。
- 品牌延展：周期战报、复盘文章与分享封面可以直接成为品牌内容。复杂矩阵应提供紧凑研究布局。

|---|---|---|---|---|

| Portfolio | 备选、Kelly、偏好、约束、组合包、排序与历史 | 光谱式配置条 | 轨道编组与敞口 | 跨页方案对比 |

| Metrics | 指标明细、统计定义、参数矩阵、相关性 | 指标到样本的透明路径 | 仪表与证据矩阵 | 数字边注与分析附页 |

这些是设计落点与接线计划。原型实现代表性布局和交互，并在每页下方给出现有功能的对应关系；并不声称已把所有生产功能复制进原型。

## 通用组件与工程边界

- 统一 tokens：画布、实底内容、玻璃、文字、次要文字、线条、主色、盈亏语义色、圆角、阴影、动效。
- 统一组件：导航、指标卡、详情层、比赛卡、组合容器、参数字段、AI 输入、分页表、状态反馈。
- 关键数字不靠夸张字号；减少长英文眉题的视觉权重，但不牺牲主标签和正文可读性。
- 玻璃只承担导航/控制层角色；依据 [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 的层级原则，在 Web 中做材质近似，不声称实现原生 Liquid Glass 的完整光学效果。
- 每个主题都具备键盘焦点、对话框关闭/焦点约束、窄屏重排、减少动态效果与不支持模糊时的降级。
- 浮层当前展示样式与数据摘要；正式接入时复用既有指标明细、云保存与校验逻辑，不再创建另一套数据源。
- 示例数据局部固定，曲线、统计卡与流水使用同一组 24 笔记录；研究矩阵等独立示意另行标注。
- 设计页按需加载，CSS 只使用 `ds-` 命名空间，不覆盖 Modern 或现有业务组件。

## 推荐与后续落地

推荐以 **HELIO 为主体系**：最贴近“水灵、苹果式现代感、优雅但可日常使用”。如果更看重叙事辨识度，可吸收 FOLIO 的章节编号、复盘编排和周期封面，但不把三套配色与圆角混在一起。

确定方向后按顺序迁移：

1. 锁定 tokens、导航和公共控件；Modern 保留作为稳定参照。
2. New / Settle 接入现有表单和 AI 状态，核验原始输入、解析、校验、保存与云同步。
3. Seasons / Overview 接入真实资金、周期与指标；核验计算口径及所有明细入口。
4. Portfolio / Metrics / Analysis 迁移高密度内容，保持计算引擎不变。
5. History / Teams / Console 补齐编辑、同步失败、空状态和响应式回归。

验收重点：不遗漏现有功能、数字和状态可追溯、桌面/窄屏可读、动效不阻塞输入、保存结果与云同步可验证。
