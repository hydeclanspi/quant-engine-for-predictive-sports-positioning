## 有意保留的研究与产品问题

- A02：AJR 回归与二元命中验证目标不同；完整生产流水线尚未统一为同一 fit/predict 验证入口。没有将当前时间切分或 Bootstrap 宣称为独立样本外收益证明。
- 新记录开始保存可用时间，但历史旧账没有该字段；没有臆造旧时间，也没有声称已经消除全部同场泄漏。
- 自适应权重的启发式目标、超参数映射、相关性模型、多重检验、独立事件簇验证仍需研究设计，本轮不替换。
- 风险限额仍为本轮/单次限额，没有擅自定义账户级在途风险政策；正 EV 时的现有 Portfolio 分配策略保留，不宣称全局 Kelly 最优。
- 同场不同市场的完整比分联合模型未实现，采用明确降级；旧记录不自动重算或迁移。
