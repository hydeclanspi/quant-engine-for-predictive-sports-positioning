# inpiration — Lab Editions / 第二轮

## 这一轮的边界

直接复用 New、Portfolio、Settle、Seasons、Overview、Metrics、Analysis、History、Teams 和 Console 的生产页面。没有重写比赛表单、AI 解析、结算、指标计算、战报明细或数据保存流程。

保留现有钻石 Logo、顶栏导航、New / Settle 的香槟 AI 输入与展开逻辑、Seasons 的完整报告结构，以及 Console 各张卡片的内部设计。改变外层构图、环境色、面板材质、边缘折光与页面间的一致性。没有增加叙事口号、假功能或装饰性大数字。

## 参考图的转译

从用户提供的荣耀截图提取的是厚透明边缘、局部彩色透光、明亮轮廓与柔和内部光晕，而不是复制截图内容。采用静态 CSS 色场、多层内阴影和渐变；不引入实时渲染、WebGL、Canvas 或新的业务动效。玻璃的明暗变化用于区分内容、控制器和浮层。

蓝色版的内容面也是蓝色，不是白卡片铺在蓝色壁纸上。输入区使用更浅的蓝色凹面维持阅读对比；原来打磨过的 AI 文本框保持内部材质与行为。

## 预览机制

- 入口：`/design/inpiration/new?edition=cobalt`。
- 方案：`prism`、`glacier`、`folio`、`cobalt`。
- 切换页面仍使用原顶栏。嵌套路径保留 `/design/inpiration` 前缀，当前方案通过 URL 和标签页偏好记忆。
- 切方案只更新样式属性，不重挂载原页面，因此不会为了比较外观清空表单。
- 预览始终使用项目原有的内存 demo 数据，即使从 `/arsenal/design/inpiration` 进入或浏览器之前已经解锁。
- 预览内的正常录入、结算与编辑通过原流程操作演示数据；不会因此提交真实投资或同步到云端。刷新后遵循现有 demo 重置行为。
- 返回应用会完整载入普通或 `/arsenal` 入口，恢复原数据加载与同步机制；原来的登录状态不因查看方案而改变。
- Modern 的样式保持原样。所有新增视觉选择器均限定在 `.lab-editions` 下，业务页面只添加少量布局定位 class。

这轮先比较整体空间与材质方向；不是将四版同时设置为正式主题，也不更改真实数据。
